# Oppimispäiväkirja: Paikallinen git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet?__

Vaikeaa ei ollut mikää, kaikki toimi niinkuin kuuluikin. Oma palava intoni oppimista kohtaan auttoi oppimaan. Selvitin esteet tahdonvoimalla ja ottamalla rukoilu taukoja.

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| ------- | ------ |
| `git init` | Luo uuden repositorion |
| `git status` | Näyttää työtilan ja staging-alueen tilan |
| `git add` | Lisää muutokset seuraavaan talletukseen |
| `git commit -m "viesti"` | Tallettaa muutokset viestin kanssa |
| `git log --oneline --graph` | Näyttää versiohistorian tiivistettynä |
| `git tag` | Lisää tunnisteen talletukseen |
| `git switch -c haara` | Luo uuden haaran ja siirtyy siihen |
| `git merge --no-ff haara` | Yhdistää haaran ja jättää yhdistämisen näkyviin historiaan |
